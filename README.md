# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보게 되는 카페 메뉴판입니다.
설치할 것 없이 `index.html` 파일 하나로 동작합니다.

## 주요 기능

- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트. 누르면 해당 메뉴만 보입니다.
- **사장님 추천 배지**: 지정한 메뉴(아인슈페너, 흑임자 라떼)에 배지가 붙고 카드가 더 돋보입니다.
- **오늘 품절 표시**: 숫자 한 글자(`0` ↔ `1`)만 바꿔서 켜고 끌 수 있습니다.
- **영업 상태 표시**: "지금 영업 중" / "오늘은 휴무일입니다"가 자동으로 나옵니다.
- **전화 걸기 버튼**: 휴대폰에서 누르면 바로 전화가 걸립니다.
- **자세히 보기**: 메뉴 카드를 누르면 설명과 가격이 아래에서 올라옵니다.

## 디자인

- 코발트 블루와 하얀색 중심의 글래스모피즘 스타일 (반투명 카드, 부드러운 그림자, 둥근 모서리)
- 휴대폰 화면(가로 390px 기준)에 맞춰 설계, 가로로 돌려도 볼 수 있습니다.
- 글꼴: 고운 돋움 (없으면 맑은 고딕), 제목에만 손글씨 느낌의 개구

## 보는 방법

1. `index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. 컴퓨터에서 휴대폰 화면처럼 보려면 `F12`를 누르고 휴대폰 모양 아이콘을 누르세요.

> 고운 돋움 글꼴은 인터넷에서 불러옵니다. 인터넷이 없으면 맑은 고딕으로 대신 보입니다.

## 내용 고치는 방법 (코딩을 몰라도 됩니다)

`index.html`을 메모장이나 VS Code로 열면, 위쪽에
**"★★★ 여기가 내가 고치는 곳입니다 ★★★"** 칸이 있습니다.
가게 정보와 메뉴가 모두 그 칸에 모여 있고, 한국어 주석으로 설명이 달려 있습니다.

메뉴 한 줄은 이렇게 생겼습니다.

```js
{ category: "커피", name: "카페라떼", price: 5000, desc: "부드러운 우유 거품", soldOut: 0 },
```

| 하고 싶은 일 | 방법 |
| --- | --- |
| 가격 바꾸기 | `price:` 뒤 숫자만 바꾸기 (쉼표나 '원' 없이. 예: `5500`) |
| 이름/설명 바꾸기 | `name:` 또는 `desc:` 의 따옴표 안 글자만 바꾸기 |
| 메뉴 추가하기 | 메뉴 한 줄(`{` 부터 `},` 까지)을 복사해서 바로 아랫줄에 붙여넣고 내용 바꾸기 |
| 메뉴 지우기 | 그 메뉴 줄을 통째로 지우기 |
| 품절로 만들기 | 그 줄 끝의 `soldOut: 0` 을 `soldOut: 1` 로 바꾸기 (되돌리려면 `0`) |
| 추천 메뉴 바꾸기 | `signatureNames` 안의 이름 바꾸기 |

고친 뒤에는 `Ctrl + S`로 저장하고 브라우저에서 `F5`로 새로고침하세요.
잘못 고쳐서 화면이 안 나오면 `Ctrl + Z`로 되돌리면 됩니다.

**지킬 규칙**: 글자는 따옴표 `" "` 안에 적기, 줄 끝 쉼표 `,` 지우지 않기, 괄호와 따옴표 지우지 않기.

```
├─ index.html      메뉴판 전체 (HTML + CSS + JavaScript가 한 파일에 들어 있음)
├─ README.md       이 문서
└─ 자료/
   ├─ CLAUDE.md    이 프로젝트를 만들 때 지킨 작업 규칙
   └─ 기획시트.png  가게 정보와 메뉴를 정리한 기획 시트
```
